# 改动说明

本仓库派生自 [Yuuyuko-uu/dsh-qq-link](https://github.com/Yuuyuko-uu/dsh-qq-link) 1.5.0，原作者 Yuuyuko-uu。
下面按「为什么改 / 改在哪 / 怎么用」逐条列。改动全部在 `lib/host.js`；`lib/client.js` 只顺着新配置项补了设置页字段。

## 一、自动换会话

**为什么**：一间会话的上下文会满，满了以后每轮都贵，也容易忘事。想让它在快满时主动说一声，然后一句话换一间。

**改在哪**：`转入一条` 开头拦本人发的命令（默认 `/new`，也认 `/新`）。

- 用 `ctx.agents.create()` 建新会话：id 随机，`agentOptions` 的 provider/model 从旧会话 projcache 的 `modelSelection` 取，取不到用 `ctx.get('agentDefaultModel').currentSelection()` 兜底。
- `meta.agentPreset` 只是名字，人设要 `ctx.get('agentPresets').mount(agentCtx, presetId)` 才挂得上；不挂，模型会说自己是助手。
- 新会话要 `workspaceRegistry.list()` 找到同路径的工作区，再 `workspace.attachSession(新id)`，否则会掉进「未分组」。
- 建完改配置里那条绑定的会话 id；旧会话用 `workspaceRegistry.archiveSession(旧id, { stopActivity: true })` 归档（文件还在，从列表里移走）。
- 命令分支 **必须调用 `已受理()`**，否则同一句 `/new` 会被轮询反复执行。

**重启后**：dsh-web 重启，会话里的 agent 会消失。`找agent` 失败时调 `ctx.agents.resume({ resumeSessionId, agentOptions })`，30 秒冷却，避免风暴。

## 二、上下文水位提醒

**改在哪**：轮询里每 30 秒读一次绑定会话的 projcache：

`storages/session_projcache/sessions/session-<键>.json` → `record.rows.contextPressure.val.pressureTokens / contextWindow`

超过 `换会话提醒比例`（默认 60%）就往私聊发一条提醒，同一间最多 `换会话提醒间隔分`（默认 30 分钟）提醒一次。

## 三、水群

**为什么**：群里有人的时候，它一句话不说会显得像挂掉了；每句都接又太吵。

**改在哪**：60 秒的定时器里调 `水群一跳()`。

- 间隔 `水群最短分`～`水群最长分` 随机（默认 60-120 分钟），每天最多 `水群每天最多` 次（默认 10）。
- 23:00-08:00 不水（`水群安静起` / `水群安静止`），时段内只把下次往后推。
- 拉 `get_group_msg_history`（count 30），只留最近两小时、非本人、纯文字、2~200 字、没看过的消息。
- 随机挑一条，连同它前面两条一起转进群会话；发送者传 `null`，避免重复署名。
- 附加提示说明「上面最后一条是随便挑的」，接不上就调 `qq_reply_gate` 传 `reply=false`。
- 群绑定行 `门槛` 要设 `true`，否则 `qq_reply_gate` 挂不上。

## 四、表情

**为什么**：她会写 `[表情:3]`，但发出去是大图——缺 `sub_type`。

**改在哪**：

- `抠正文表情()` 认 `[表情:N]`（1-80）与 `[表情图](路径)`，从正文里抠掉，另发一张图。
- 发送时 image 段带 `sub_type: 1` 与 `summary: '[动画表情]'`，客户端才显示成小表情。
- `表情文件(序)` 按 png/gif/webp/jpg/jpeg 依次找实际文件——收藏的表情常是 jpg，扩展名别信。
- 兜底：她写 `![说明](路径)`，只要路径含 `qq-bridge-inbox` 或表情目录，就按表情发（判断用原始路径 `源.value`，不能用转换后的路径）。

表情库默认在 `~/.dsh/qq-faces/`，可用环境变量 `DSH_QQ_FACES` 改。

## 五、日志

`记账()` 除了走 `ctx.logger`，还 `appendFileSync` 写一份 `~/.dsh/qq-bridge.log`——服务器上 `ctx.logger` 不一定落盘，排查全靠它。

## 六、新增配置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `换会话提醒比例` | 60 | 上下文用到百分之几就提醒 |
| `换会话提醒间隔分` | 30 | 同一间最多多久提醒一次 |
| `换会话命令` | `/new` | 本人发这个就换会话 |
| `水群开` | true | 水群总开关 |
| `水群最短分` / `水群最长分` | 60 / 120 | 两次水群的间隔范围 |
| `水群每天最多` | 10 | 一天最多几次 |
| `水群安静起` / `水群安静止` | 23 / 8 | 安静时段，按服务器本地时间 |

## 七、没改的部分

收发、图片、语音、门槛、试运行这些，都是原版的逻辑，一行没动。改动只做加法。
